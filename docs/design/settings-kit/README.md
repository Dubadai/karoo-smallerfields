# Settings kit in SmallerFields

SmallerFields' pages built from the shared settings kit (`SettingsKit.kt`, from karoo-starter;
rules: `karoo-starter/docs/design/settings-kit/README.md`). Pictures from the Android 12L emulator
(`Karoo3-api32`), light, in the Karoo 3 on Sky.

- `01-list`, `02-list-end`: SmallerFields, "Your fields" as list cards with each field's tile, "+ Add
  field" (kit ADD), then the app rows (update notices, version).
- `03-edit`, `04-edit-colours`, `05-edit-end`: a field's page. The Example card scrolls with the page;
  tap a half to pick which data the colour controls set. Kit order: layout, tiles, colours, then
  First / Second, then Delete field (kit REMOVE).
- `06-add-step1`, `07-add-step4`: Add field keeps its four steps and the fixed button at the bottom,
  now the kit's yellow MAIN button (the step frame stays SmallerFields' own for now).
